### Architecture
- **Frontend**: React components + Firebase Messaging SDK
- **Backend**: Firebase Cloud Functions triggered on Firestore writes
- **Service Worker**: Handles background push notifications
- **Token Management**: FCM tokens stored in user documents (fcmTokens array)

### Features
- Permission request prompt (appears 3 seconds after login)
- Foreground message handling with local notifications
- Background message handling via service worker
- Multi-device support (all user tokens notified)
- Invalid token cleanup
- Settings panel for enabling/disabling notifications
